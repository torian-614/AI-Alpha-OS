# Decision

归档 Alpha 生命周期中的推进、退回、暂停和退役决策，使研究证据、比较结果与最终结论可追溯。

## 记录内容

- 决策标识、日期、状态、提出者与审查者。
- 关联的 Alpha、研究实验、回测运行及 Arena 比较记录。
- 已获得的证据、已知局限、备选行动及采纳理由。
- 原状态、目标状态、适用条件、复审条件和后续任务。

决定必须由维护者或指定审查者明确确认；Agent 输出或排名不能自行授权执行交易。被替代的决策保留并链接后继记录。

## 职责边界

本目录保存研究与生命周期决策。[ADR](../docs/architecture/decisions/README.md) 保存语言、框架和模块边界等工程架构决策，二者通过链接关联。

Sprint 0.2 仅定义文档归档位置，没有决策引擎、订单逻辑或交易执行能力。
