# Sprint 1.2 — Design Core Quant Architecture

## 目标

建立量化系统核心设计文档，连接 [MVP PRD](../product/MVP_PRD.md) 的数据、分析、信号和模拟验证闭环。本次不开发任何代码，包括 Python、行情接口或交易执行实现。

## 完成内容

- [x] 创建 [DATA_CONTRACT.md](../data/DATA_CONTRACT.md)，定义股票基础、日线、分钟、竞价、龙虎榜、板块和情绪七类数据的字段、类型与用途。
- [x] 定义单位、业务键、空值、版本、可用时间及质量约束，补充交易日历、规则和权益事件支撑语义。
- [x] 创建 [ALPHA_SCORING.md](../alpha/ALPHA_SCORING.md)，建立竞价、板块、龙头、情绪周期和风险控制五维框架。
- [x] 保留 PRD 的情绪修复与首板二进场景，明确最终参数未来通过回测优化。
- [x] 创建 [BACKTEST_RULES.md](../backtest/BACKTEST_RULES.md)，定义买卖、成交、费用、滑点、最大回撤与胜率口径。
- [x] 补齐新增文档目录 README，同步架构入口、文档索引、路线图和变更日志。

## 验收标准

| 标准 | 文档验收依据 |
| --- | --- |
| 七类数据完整 | 每类具有字段名称、类型、用途、粒度和业务键；共同元数据统一继承 |
| 历史数据可追溯 | 明确 available_at、版本、历史成员、修订及缺失值处理 |
| 评分框架清楚 | 五个维度有输入与输出，映射 PRD；权重、阈值、窗口未设最终值 |
| 回测规则完整 | 买入、卖出、成交、手续费、滑点及统计口径均可查阅 |
| 计算定义可核对 | 最大回撤和胜率有公式、分母、边界条件及合成示例 |
| 文档一致 | 内部链接有效，数据字段与评分、回测引用一致，区分设计与实现 |
| 提交范围正确 | 仅 Markdown 文档，全部修改以一次指定 commit 交付 |

文档检查不代表数据接入、Alpha 计算或回测测试通过。业务验收场景留待独立实现任务执行。
