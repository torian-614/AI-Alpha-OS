# Architecture Decision Records

保存重要设计决策及其理由。目前没有已采纳的技术选型决策。

## 命名与状态

文件格式：NNNN-short-title.md，例如 0001-runtime-selection.md；编号递增且不复用。

状态使用 Proposed、Accepted、Rejected 或 Superseded。提案需经维护者审查后才能标记 Accepted；被替代的决策保留并链接后继记录。

## 记录模板

新建 ADR 时填写以下内容，并在本页添加链接：

- 标题：编号与决策名称。
- 状态与日期：当前状态、提出日期和采纳日期（如适用）。
- 背景：问题、约束和相关需求。
- 备选方案：可行选择及优缺点。
- 决策：采用的方案与原因。
- 后果：收益、成本、风险和后续工作。
- 关联：相关任务、文档及被替代的决策。
