# AI Alpha OS Alpha 评分公式规范

任务：Sprint 1.7 — Define Alpha Formula Specification。日期：2026-09-17。

状态：第一版研究公式提案，未实现、未回测、未验证盈利能力。本文首次给出暂定数学组合，不将暂定权重标记为最终参数，不提供 Python、SQL 或策略代码。

## 一、Alpha评分设计原则

1. 可解释：每一分可拆解为原始输入、因子、方向和权重贡献。
2. 可计算：明确定义分母、时间窗口、归一化、缺失值与异常分支。
3. 可回测：固定数据、规则、参数及交易评价协议，可重现历史结果。
4. 可优化：参数可版本化搜索，但不能在样本外反复调参。
5. 可比较：同对象、同时间、同版本和同评价股票池内比较，不把相同数字解释为相同盈利概率。

所有有效 Alpha 输出统一为 **0–100分**。Alpha001–Alpha004 越高表示对应机会、环境或强度越高；Alpha005 越高表示风险越大。缺失或非法配置输出 null 与原因，不以 0 伪装正常计算。

沿用 [数据映射](ALPHA_DATA_MAPPING.md)、[评分框架](ALPHA_SCORING.md)、[回测规则](../backtest/BACKTEST_RULES.md) 与 [研究协议](../research/RESEARCH_PROTOCOL.md)。本次只补充公式提案，不改变准入与实盘边界。

## 二、标准结构与公共算子

### Alpha 标准结构

每个 Alpha 必须记录 Alpha ID、名称、目标、输入字段、计算因子、权重设计、评分公式、输出结果、验证指标，并附 strategy_version、parameter_version、input_data_version、signal_time 和 decision_id。

表中因子从左到右对应公式编号 j=1…5。每个模型暂定五因子等权 w_j=0.20，作为无偏好研究对照；正式研究可搜索非负权重且总和为 1。**这些权重尚未验证，不能人工固定为最终版本。**

### 公共定义

| 记号 | 定义与边界 |
| --- | --- |
| t、d、d-1 | 决策时点、所在交易日、上一完整市场交易日 |
| W | 参数版本中指定的历史窗口长度，正整数；禁止隐含默认窗口 |
| mean_W(x) | 当前观测之前 W 个预期历史时点的算术均值；缺少必需时点则输入不足，不能临时缩短 |
| clip(x) | min(1, max(0, x)) |
| U(x;a,b) | clip((x-a)/(b-a))，要求 b>a；表示越大越强或越大越危险，依模型方向 |
| D(x;a,b) | 1-U(x;a,b)，表示越小越强 |
| B(x;a,b,c,d) | 梯形偏好：x≤a 或 x≥d 为0；a<x<b 为(x-a)/(b-a)；b≤x≤c 为1；c<x<d 为(d-x)/(d-c)，要求 a<b≤c<d |
| N、U_count、D_count | 冻结股票池有效证券数、当时涨停数、跌停数；N>0且覆盖通过检查 |
| r | 一致口径的收益小数，例如0.05表示5%；行情金额单位元、成交量单位股 |
| PctRank(x) | 同时点同股票池内 (小于x的数量+0.5×等于x的数量)/有效数量，输出0–1；池为空无效 |

归一化 a、b 等边界按因子单独登记，可由训练区间的预注册分位数估计，也可搜索有含义的候选值；最终必须有具体数字并冻结。相同边界、无有效样本或未配置则 invalid_config，不通过加入任意 epsilon 掩盖问题。

比例分母为零或未知时默认输入不足；原始事实明确为零且公式无需除以该值时，零可参与计算。炸板率没有触板分母时仍为 null，本研究基线拒绝完整评分；如需单独“无触板”状态，必须新建规则版本。

股票/板块历史比率基准使用同一证券/板块、同一时段、同一交易方式及单位；盘中累计量只与历史同截止时刻比，不与全天量混比。分数计算不使用尚未完成的当日数据。

### 时点与计算模式

- 基线为盘前研究：个股日线、涨停梯队、板块和市场因子使用上一完整日及更早数据；竞价使用当前可用快照。
- 收盘后可生成下一交易日候选；事件后盘中更新需单独 mode 与版本，不能把盘后因子回填盘前。
- final 竞价数据可用后生成的信号不能参加已经结束的同次竞价成交。
- sector_data、sector_strength、market_data、index_data 的物理契约仍待补齐，字段来源和缺口见数据映射，不视为已接入数据。
- 预处理和权重只在允许的训练数据拟合；输出时所有依赖必须 available_at≤t，前向模拟还要求 ingested_at≤t。

## 三、Alpha001：竞价强度评分

名称：竞价强度Alpha。目标：识别开盘前具有资金关注度的股票；“关注度”是量价代理，不证明资金主体意图。

输入：auction_data、daily_price、limit_up_ladder、sector_strength。

| 因子 | 输入字段与原始量 x | 因子 F_j（0–1） |
| --- | --- | --- |
| 开盘涨幅因子 | auction_data.open_gap_percent = auction_price / prev_close - 1 | F_1 = B(x;a_1,b_1,c_1,d_1)，过高涨幅不无限加分 |
| 竞价金额强度因子 | x = auction_data.auction_amount / mean_W(daily_price.amount)，历史量额截止d-1 | F_2 = U(x;a_2,b_2)，表示竞价金额相对历史全天流动性 |
| 竞价成交量比因子 | x = auction_data.auction_volume / mean_W(历史同阶段同类型竞价量) | F_3 = U(x;a_3,b_3)；不能混用 indicative 与 final |
| 板块强度因子 | 已可用 sector_strength.sector_strength_score，历史成员映射 | F_4 = sector_strength_score / 100 |
| 昨日涨停/连板状态因子 | c = d-1 的 limit_up_ladder.consecutive_days；完整状态确认为非涨停则c=0 | F_5 = U(c;0,C_cap)，C_cap>0为待优化饱和高度 |

多板块归属时，基线对当时已知概念板块的有效评分等权平均；没有概念时使用已知主行业。需固定成员及板块覆盖，不能事后选最强板块；关键覆盖不足则拒绝评分。

评分公式：

auction_score = 100 × Σ(w_1j × F_j)，j=1…5

暂定 w_1=(0.20,0.20,0.20,0.20,0.20)，后续通过回测优化。输出股票分数、候选排名和触发依据，是否生成模拟交易信号由独立冻结阈值决定。验证采用下文共用四项指标，并报告竞价覆盖与未成交比例。

## 四、Alpha002：情绪周期评分

目标：判断市场当前环境。输入：limit_up_ladder 与 market_data（market_sentiment 和指数上下文的时点视图）。

| 因子 | 输入与原始量 | 因子 F_j |
| --- | --- | --- |
| 涨停数量 | market_sentiment.limit_up_count / N | F_1 = U(x;a_1,b_1) |
| 跌停数量 | market_sentiment.limit_down_count / N | F_2 = D(x;a_2,b_2) |
| 连板高度 | market_sentiment.max_consecutive_limit_up，与梯队核验 | F_3 = U(x;a_3,b_3) |
| 炸板率 | market_sentiment.failed_limit_up_rate | F_4 = D(x;a_4,b_4) |
| 市场成交额 | market_turnover / mean_W(同范围历史成交额) | F_5 = U(x;a_5,b_5) |

用占比表达涨跌停数量，防止股票池规模变化直接提高分数；同时保存原始数量、N和覆盖。连板高度的单调正向关系只是初始假设，需检验拥挤与退潮阶段失效情况。

market_state_score = 100 × Σ(w_2j × F_j)

暂定 w_2 各为0.20。高分表示研究假设下市场较适合进攻，低分表示风险提高；不自动下单。

状态阈值暂定为参数而非数值：T_low<T_high。分数≥T_high为进攻，T_low≤分数<T_high为防守，分数<T_low为空仓等待候选状态。具体阈值未来通过回测确定，缺参不发布状态。

验证在固定基础策略上比较有无市场状态控制后的胜率、收益率、最大回撤、夏普比率，以及持仓暴露变化。

## 五、Alpha003：龙头强度评分

目标：识别市场核心标的。输入：limit_up_ladder、daily_price、sector_data。

| 因子 | 输入与原始量 | 因子 F_j |
| --- | --- | --- |
| 连板高度 | d-1完整日 consecutive_days | F_1 = U(x;0,C_cap) |
| 首次涨停时间 | first_limit_time 距该日可交易时段起点的累计交易分钟 m；午休不计，时段来自交易日历 | F_2 = D(m;0,M_session)；M_session为该日对应会话总分钟数 |
| 成交量变化 | d-1 volume / mean_W(d-2及更早volume) | F_3 = B(x;a_3,b_3,c_3,d_3)，避免放量越大越好 |
| 板块地位 | 股票 d-1 change_percent 在所属板块内的 PctRank，与该板块的排名强度 q 结合 | F_4 = (PctRank + q)/2；q=(K-rank)/(K-1)，K>1；K=1时q=0.5 |
| 资金关注 | d-1 daily_price.amount / 同日冻结股票池总amount | F_5 = U(x;a_5,b_5)，只是成交额份额代理 |

板块地位复用 Alpha001 的固定成员聚合规则；rank 采用冻结的唯一排序与并列处理，K为有效板块数。首次涨停从未发生且证据完整时 F_2=0；发生状态或时间未知时输入不足，不能把未知当作最晚时间。

leader_score = 100 × Σ(w_3j × F_j)

暂定 w_3 各为0.20。输出股票评分、龙头候选与排名；“龙头”是当时规则的候选身份，不以未来涨幅倒推。验证采用固定入场/退出协议和四项共用指标，额外比较同板块基准。

## 六、Alpha004：板块强度评分

目标：识别市场主线。输入：sector_data、daily_price 及历史板块成员关系。

| 因子 | 输入与原始量 | 因子 F_j |
| --- | --- | --- |
| 板块涨幅 | sector_data.return_rate，固定成员及聚合口径 | F_1 = U(x;a_1,b_1) |
| 成交额变化 | sector_data.turnover / mean_W(此前同范围板块成交额) | F_2 = U(x;a_2,b_2) |
| 涨停数量 | sector_data.limit_up_count / 有效成员数 | F_3 = U(x;a_3,b_3) |
| 核心股票表现 | 此前已确定核心集合在最新已完成日的收益等权均值 x | F_4 = U(x;a_4,b_4) |
| 持续性 | 截至最新已完成日，最近W日板块收益超过预选基准指数收益的天数/W | F_5 = x，完整W日不可缺失 |

核心集合从前一评价时点已经确认的候选中按固定规则选择，首次运行使用预注册历史量价规则形成种子；不能由同一时点待计算 Alpha003 反向产生。指数基准由 index_data 支撑，不能隐去该外部依赖。

sector_strength_score = 100 × Σ(w_4j × F_j)

暂定 w_4 各为0.20。输出板块评分与排名，并作为已完成结果供 Alpha001/003 引用。验证前固定板块到可交易股票组合的映射，报告四项共用指标，不把板块得分当收益。

## 七、Alpha005：风险评分

目标：控制回撤。输入：market_data、daily_price；极端事件还需可审计 risk_event 逻辑输入扩展，当前尚未定义物理表。

| 因子 | 输入与原始量 | 风险因子 R_j（0–1，越高越危险） |
| --- | --- | --- |
| 指数趋势 | 指定指数最新已完成收盘 I / mean_W(此前指数收盘) - 1 | R_1 = D(x;a_1,b_1) |
| 市场波动率 | 指定指数最近W个有效日收益的样本标准差，W≥2；不与个股波动混用 | R_2 = U(x;a_2,b_2) |
| 跌停数量 | market_sentiment.limit_down_count / N | R_3 = U(x;a_3,b_3) |
| 情绪退潮信号 | (前一有效 market_state_score - 当前已完成 market_state_score)/100 | R_4 = clip(x)，只对下降计风险 |
| 极端风险事件 | t时刻有效事件集合的已登记severity（0–1） | R_5 = max(severity)；可信监测确认无事件时为0 |

risk_event 至少需 event_id、scope、severity、hard_block、effective_from、effective_to、available_at、source、evidence_ref 和 data_version。事件严重度映射预先冻结；无监测能力不等于无事件，应输出 unknown。市场事件传播到市场消费者，股票事件只传播到受影响证券。

risk_score = 100 × Σ(v_j × R_j)

暂定 v 各为0.20。hard_block=true 或关键数据不可信时，独立闸门令 eligible=false、total_score=null；不能因均值风险分数较低忽略极端事件。监管和交易制度硬约束不属于收益优化参数。

此基线以市场风险为主，股票输入用于身份、价格质量、状态及受影响范围检查；若新增个股波动风险因子，应新建版本，不偷偷替换“市场波动率”。

验证比较相同基础策略有无风险层的四项指标，并报告拒绝率、暴露、漏过机会与极端情景表现；不以长期空仓单独证明有效。

## 八、综合评分模型：Total Alpha Score

用户流程中的连接符表示评分组成，不将高市场环境分、龙头分或板块分作为负贡献。

对同一股票、同一决策时点，令 A=auction_score、M=market_state_score、L=leader_score、S=映射到股票的sector_strength_score、R=risk_score：

Opportunity = β_A×A + β_M×M + β_L×L + β_S×S

RiskPenalty = λ×R

Total Alpha Score = 100 × clip((Opportunity - RiskPenalty)/100)

约束：β非负且和为1，λ≥0。研究基线 β=(0.25,0.25,0.25,0.25)，λ=0.25；全部为暂定对照，不是可直接上线的最终参数。权重最终必须通过历史回测优化、滚动验证、样本外与前向模拟审查，不能人工固定为最终版本。

市场状态和板块分是上下文，须先按对象关系与时点映射到股票。未配置、必需分数缺失、事件监测未知或硬闸门拒绝时不发布有效总分，不将其强排为最后一名。

综合排序：按 Total Alpha Score 降序，同分按稳定 stock_id 升序，只在同一 ranking_batch_id 内比较。保存各分项、权重、RiskPenalty、数据/参数版本和排名股票池；总分不是盈利概率。

竞价分中已有板块因子，龙头分也含板块地位，风险分含情绪变化，可能重复暴露。研究必须做相关性、去因子对照与权重敏感性检查；不能因“加了更多项”就认为信息更多。

### 数学边界核对（合成示例）

五个归一化因子全为0时对应评分0，全为1时评分100，均为0.5且等权时评分50。

A=80、M=60、L=70、S=90、R=40 时，等权 Opportunity=75，RiskPenalty=10，Total=65。若硬闸门拒绝，输出为 null 而不是65。若 Opportunity=10、RiskPenalty=20，总分截断为0。以上只是公式核对，不是回测收益或策略结果。

## 九、参数优化机制

### 参数清单与冻结

每次实验保存五组权重、β、λ、所有窗口、归一化边界、C_cap、状态阈值、历史基准、成员聚合、极端事件规则、入场/退出协议和评价时间分区。所有必需参数有明确数值后才可运行，不能把本文件中的符号当作已配置。

| 方法 | 设计要求 |
| --- | --- |
| 网格搜索 | 事先登记有限搜索范围与试验预算；权重满足单纯形约束，记录所有失败和成功组合 |
| Walk Forward验证 | 按时间顺序训练→验证→后续窗口评价；每折仅使用此前可用信息拟合归一化和权重，边界和滚动计划预先冻结 |
| 样本外测试 | 在候选冻结后使用未触碰区间，不能看结果后回调参数并继续称为独立测试 |
| 参数稳定性测试 | 比较邻近权重、阈值和窗口，对市场阶段、股票池、成本与数据源变动进行敏感性分析 |

选择规则需预注册，例如在已冻结回撤与样本量约束下比较收益及风险调整表现，不能结果出来后更换选优标准。手续费、真实交易约束不能为了提高收益而优化；滑点可作保守敏感性场景。

标签或持有期跨分区时采用预注册隔离规则；记录多重尝试数量，优先研究稳定区间而非孤立最优点。样本不足、数据泄漏或指标不可计算时不能通过验收。

### 共用验证指标

- 胜率：净盈利闭合持仓周期数/全部闭合周期数，零盈亏计分母，无闭合周期为null。
- 收益率：含成本净值 E_T/E_0-1，注明区间与现金流假设。
- 最大回撤：净值相对此前峰值的最大下降比例，注明估值频率。
- 夏普比率：遵循 [数据映射中的统一口径](ALPHA_DATA_MAPPING.md)，固定收益频率、无风险假设与年化参数；无有效方差或样本不足为null。

同时披露样本量、未成交、覆盖、持仓暴露、成本及参数搜索记录。模型评分能力与收益能力分别评价，不能把公式输出正常视为策略有效。

## 十、Alpha生命周期

```text
Research → Backtest → Validation → Paper Trading → Production → Retirement
```

Research 包含 Idea、Hypothesis、Data 的登记和预注册。Validation 包含 Walk Forward、独立 Out-of-Sample 与参数稳定性检查，不删除已有研究协议的任何关卡。

Production 前须完成 Paper Trading、研究 Approved、工程验证与明确部署授权；Production 可为模拟生产，不自动表示实盘。任何 Alpha 不能直接进入实盘。

失败可 Rejected、暂停或返回受影响阶段；规则与参数更新创建新版本，不能继承旧版本的有效性结论。Retirement 保存退役原因和证据，停止新信号，既有持仓按单独风控流程处置，不删除历史。
