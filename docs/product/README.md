# 产品范围

## 愿景

AI Alpha OS 是一个以长期稳定盈利为最高目标的 A股量化交易系统，遵循非黑箱与开源透明原则。

## 产品需求入口

- [MVP 产品需求文档](MVP_PRD.md)：定义 V1 范围、使用流程、排除项及成功验收标准。
- [项目章程](../project/PROJECT_CHARTER.md)：项目目标、基本原则与 Alpha 生命周期管理。

## 当前阶段

Sprint 1.1 交付第一版 MVP PRD。第一阶段围绕数据 → 分析 → 信号 → 模拟交易 → 结果反馈 → 策略优化建立闭环，验证是否能通过数据与规则发现具有历史有效性的 Alpha。

当前仓库仅有工程结构和文档；PRD 中的功能属于待实施需求，不代表系统已经具备数据接入、评分、回测或模拟交易能力。

## V1范围

市场状态分析、五类 Alpha 评分、历史回测及决策追踪。详细需求以 [MVP_PRD.md](MVP_PRD.md) 为准。

V1 暂不开发自动实盘交易、100个虚拟游资竞技场、大模型训练或高频交易。

## 后续待明确事项

数据范围与授权、指标和评分口径、模拟条件、历史有效性评价标准，以及模块边界、技术栈和部署方式，均需在后续设计与任务中明确。
