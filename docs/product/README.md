# 产品范围

## 愿景

建设开源的 AI 量化交易操作系统，为未来产品设计、研究和工程协作提供统一项目基础。

## 当前目标

Sprint 0 Day 1 的使用者是项目维护者与贡献者。交付可导航的仓库结构、文档分类和协作规则，使后续任务有明确归档位置与验收依据。

## 当前排除项

不实现交易策略、AI 模型、行情接口、回测引擎或交易执行。不提供可运行服务和产品界面。

## 待明确事项

- 目标用户与核心使用场景。
- MVP 功能范围及非功能要求。
- 模块边界、技术栈和发布方式。

待定事项需在后续任务中形成可审查的需求与验收标准。
