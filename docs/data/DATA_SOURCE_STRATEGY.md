# AI Alpha OS 数据源策略

状态：Sprint 1.3 管理规范。仅定义数据源选择、评估和运行治理，不选定供应商、不接入接口、不开发代码。字段与时点语义以 [DATA_CONTRACT.md](DATA_CONTRACT.md) 为准。

## 一、数据源选择原则

1. 先满足研究需求，再比较价格：以股票池、频率、历史期间、字段和可用时间为依据，不能用“能下载”代替“适合研究”。
2. 来源可追溯：明确原始提供方、转发链路、文档与版本；包装库不自动成为独立数据源，两个入口可能依赖同一上游。
3. 使用条件明确：核对研究、缓存、长期留存、展示及再分发权限，保存条款版本和评估日期。免费访问不代表可以任意使用或再分发。
4. 满足历史时点要求：能说明 event_time、available_at、修订、复权及历史成员口径；无法验证当时可用性的数据不能支撑时点敏感的结论。
5. 质量与连续性可验证：评估缺失、重复、延迟、限流、修订和服务中断；不以一次成功请求作为稳定性结论。
6. 公开评估方法与结果摘要，受限原始数据和凭据不进入仓库。
7. 接受能力边界：缺少所需竞价或分钟数据时暂停相应研究，不以日线伪造缺失信息。

## 二、免费数据源评估标准

所有候选使用同一预先定义的样本范围和评估窗口。比较结果为 pass、conditional、fail 或 not_evaluated；尚未实测不能填写 pass。

| 维度 | 核查内容 | 必须保留的证据 |
| --- | --- | --- |
| 授权与可持续使用 | 许可范围、请求限制、缓存与分发条件、条款变化 | 官方条款链接、核查日期、限制清单 |
| 字段与语义 | 股票身份、单位、精度、复权、交易时段和字段映射 | 与数据契约逐字段对照及缺口 |
| 历史覆盖 | 每类数据最早/最晚日期、股票与频率覆盖、退市及历史成员 | 覆盖矩阵、缺口和排除样本 |
| 时点可用性 | 发布时间、接收延迟、竞价 indicative/final 区别、修订记录 | 时间样本、发布说明及可用时间推定依据 |
| 完整性与正确性 | 业务键、必需字段、量价关系、缺失与异常 | 抽样核对、质量报告及异常明细 |
| 稳定性 | 观察期内成功率、超时、限流、延迟和重复获取一致性 | 观察窗口、请求统计、故障记录 |
| 可复现性 | 是否能固定原始响应、版本和历史快照 | 合法留存方式、清单、校验值 |
| 维护成本 | 字段变化、文档质量、依赖与人工修复需求 | 变更记录与预计维护事项 |
| 替代能力 | 与备用源的上游独立性及交叉覆盖 | 上游依赖图、重叠区间对照 |

授权不明、关键字段缺失、无法证明可用时间或关键历史覆盖不足，均为对应研究用途的阻断项，不得以其他维度高分抵消。conditional 必须限定用途与有效期，不能用于被限制的研究。

具体抽样规模、延迟阈值、观察期和允许缺失比例由数据负责人在评估前登记，审查后冻结；未登记则不得宣布通过。本规范不预设未经验证的服务水平。

## 三、数据源登记与责任

每个数据集分别登记候选，不要求一个供应商覆盖全部七类数据。

| 登记项 | 内容 |
| --- | --- |
| source_id / upstream_id | 提供方及原始上游标识 |
| dataset / role | 数据集名称；primary、backup 或 comparison |
| scope | 交易所、板块、股票池、频率、字段、起止日期 |
| mapping_version | 到数据契约的转换与单位映射版本 |
| availability_policy | 发布时点证据、延迟及修订处理规则 |
| access_and_license | 使用权限、配额、留存限制与依据；不记录密钥 |
| evaluation_ref | 样本、阈值、质量报告及评估结论 |
| owner / reviewer | 维护负责人和审查者 |
| status / effective_period | candidate、qualified、suspended、retired 及有效区间 |
| limitation / review_due | 已知缺口、允许用途和复审期限 |

数据负责人维护登记、质量事件及修复；审查者确认资格、适用范围和切换结论。角色可以由同一维护者承担，但审批理由与证据必须明确记录。

## 四、主数据源与备用数据源设计

- 每个数据集及适用范围指定一个合格主源，固定选择规则版本。备用源必须独立完成同等用途评估，不因“备用”降低质量门槛。
- 优先选择上游故障相互独立的备用源；若实际共享上游，记录共同失效风险，不称为独立备份。
- 备用源需与主源在重叠区间比较单位、复权、时间标签、字段含义和修订口径。未经证明等价的字段不拼接，不对冲突价格取平均。
- 暂无合格备用源时显式登记单源状态、受影响研究及停止条件；不能虚构备用能力。历史研究可使用已冻结且授权留存的合格快照，实时模拟需按新鲜度要求判断能否继续。

### 切换流程

发现中断或质量异常 → 隔离受影响批次 → 记录事件与影响范围 → 检查备用资格及覆盖 → 重叠样本核对 → 审查切换 → 发布新快照与选择规则版本 → 验证消费者恢复。

切换记录包含主备 source_id、故障原因、起止时点、受影响证券与字段、核对结果、审查者和恢复条件。自动故障切换若后续实施，必须先定义经过审查的触发条件；当前不实现自动切换。

每条记录保留真实来源和 lineage_refs。切换不覆盖旧快照；同一研究对比必须固定数据选择版本。研究中途换源时暂停并登记实验偏离，重新验证影响，不能继续后宣称环境完全相同。

主源恢复后先完成修复和重叠核对，再决定是否切回。来源差异未解决时保持隔离，不根据哪份数据能提高收益来选源。

## 五、数据质量检查机制

原始数据留存（仅限授权范围）→ 契约映射 → 批次质量检查 → 隔离或发布不可变快照 → 消费前复查 → 持续监测。

| 层次 | 检查内容 | 不通过处理 |
| --- | --- | --- |
| 身份与结构 | 字段类型、业务键唯一、证券引用、版本和单位 | 隔离错误记录或批次，禁止发布为合格数据 |
| 时间 | 交易日历、bar 边界、available_at、历史有效区间与修订 | 阻断存在未来信息或无法定位时点的消费 |
| 完整性 | 必需字段、证券覆盖、预期时段、断档及更新新鲜度 | 记录缺失范围；关键依赖不足则停止对应评分或模拟 |
| 数值 | 价格区间、非负成交量、限价适用性、复权与权益一致性 | 标记并复核，禁止无依据改价或填零 |
| 跨源核对 | 同口径、同时间、同证券的差异 | 记录差异和容差依据；按权威性与证据裁定 |
| 派生一致性 | 板块成员、情绪聚合、分母和 lineage_refs | 重新核查输入与算法版本，保留原版本 |
| 持续运行 | 延迟、失败率、字段漂移、授权或覆盖变化 | 触发事件、暂停资格或重新评估 |

覆盖率 = 实际有效业务键数 / 预期业务键数。预期集合来自冻结股票池和交易日历，明确停牌、无成交及不适用记录的预期表现；不能通过删除缺失证券提高覆盖率。分母为零时标为不适用，不报告 100%。

阻断级问题禁止相关快照进入正式研究；警告级问题只有在预先审查的用途和容差内才可放行，报告中披露影响。阈值按数据类和用途冻结，不根据回测效果调整。

质量事件保存 issue_id、批次、来源、规则、严重级别、样本、影响范围、负责人、处置及复检证据。修正数据产生新 revision 和 dataset_version，通知受影响实验，不覆写已引用的历史证据。

## 六、历史数据覆盖要求

覆盖以具体研究依赖为准，而非统一声称“支持全部历史”。正式实验前保存覆盖矩阵：数据类 × 股票池 × 频率 × 起止时间 × 缺口 × 可用时点证据 × 可用用途。

| 数据类 | 最低语义覆盖要求 |
| --- | --- |
| 股票基础数据 | 历史上市、退市、名称、风险状态、股本和有效期，不能只保留当前存续股票 |
| 日线行情 | 研究区间及特征预热区间；原始价格、量额、状态、涨跌停边界及权益配套 |
| 分钟数据 | 所选撮合粒度覆盖完整模拟窗口，明确停牌、缺失与竞价是否重复计入 |
| 竞价数据 | 明确 opening/closing、indicative/final、历史快照密度和发布时点；final 不能代替历史过程快照 |
| 龙虎榜数据 | 覆盖披露期间、原因、席位与实际发布时间；不使用时登记为非依赖，不视为已支持 |
| 板块数据 | 当时可知的分类、成员变动及统计版本，不能以当前板块成员回填历史 |
| 情绪数据 | 可复现的历史股票池、量价输入及指标版本，周期标签不得由未来走势倒推 |
| 支撑数据 | 交易日历、历史规则、权益事件和必要复权因子，覆盖整个持仓与估值区间 |

研究时间安排必须包含特征预热、训练、验证和未使用的样本外区间，并覆盖预先声明的适用市场状态。最短年限、闭合交易数和 Paper Trading 观察长度不在本次任意设值；研究负责人必须在 Hypothesis 阶段制定并经审查冻结。

数据不足则缩小结论适用范围、延后研究或拒绝候选，并记录原因；不得对缩短后的样本仍声称达到原覆盖要求。不同数据频率起点不一致时，以全部必需依赖的共同可用区间确定可评估范围。

Paper Trading 使用未来逐时到达的信息，历史数据回放不能替代其观察记录。接入计划与实际已覆盖范围分别登记。
