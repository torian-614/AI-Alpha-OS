# 量化研究文档

用途：归档经授权的研究问题、假设、评估方法及结论。当前没有研究结果或策略实现。

- [量化研究协议](RESEARCH_PROTOCOL.md)：Idea → Hypothesis → Data → Backtest → Out-of-Sample → Paper Trading → Approved / Rejected。

任何策略进入系统前必须完成协议规定的验证与批准；研究和模拟阶段的候选必须保持未批准状态。

后续记录应说明研究问题、数据来源及使用权限、评估区间、可复现条件、结果与局限。未经执行的实验必须标注为计划。

本目录保存研究方法与通用约定；具体候选、实验及报告归档在根目录 [research/](../../research/README.md)。两者通过链接关联，避免复制产生冲突。
